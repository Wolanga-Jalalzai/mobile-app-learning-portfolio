# Module 1 Analysis

In this module, I learned the basic structure of a Kotlin program,
including the main function, variables, data types, string templates,
calculations, and functions.

Using Int values for the number of adults and children allowed Kotlin
to perform mathematical addition. When the values were stored as
String values, Kotlin joined them as text instead of calculating their
sum.

I also learned the difference between val and var. A val cannot be
reassigned after initialization, while a var can be updated. Therefore,
var is appropriate when a value is expected to change.
